# Process

This lane documents the mechanics of the issue-to-PR workflow itself. Use it
when changing prompts, stages, gates, fixup routing, or the auto-research loop.
Use [../glossary.md](../glossary.md) as the normative vocabulary for stage,
gate, candidate, and export terms.

Expected topics:

- staged attempt lifecycle, from setup through candidate;
- read-only research responsibilities;
- implementation, verification, audit, review, and fixup contracts;
- review/fix loop routing and visit budgets;
- auto-research protocol for proposing, testing, and promoting workflow
  changes.

Keep historical experiment results in `../experiments/`. This directory should
describe how the process is supposed to work now, not every path that led here.
